# Classer v0.8.0

- Correct legacy unpaid class fees using their student baseline, including the old duration snapshot bug. Add a versioned baseline and display the calculation. Paid receipts and negotiated historical amounts remain unchanged.
- Store independent session notes with creation/edit timestamps. Preserve old notes and status history; add, edit and delete notes without changing financial receipts. Legacy notes without timestamps are labelled explicitly.
- Require a phone number for class requests. Append internal admin notes and dated follow-up events. Approval refers a request only to the selected teacher; teachers can add the applicant to their own roster, with duplicate and retry protection.
- Add administrator-controlled default and student-specific commission percentages, referral-specific terms and currency-safe splits. Show gross fees and teacher/admin shares throughout teacher finance, receipts, dashboards and the admin financial report. Settled shares are immutable; students see only gross class fees.
- Put public profile before qualifications and specialties, keeping gender only in the public profile section.
- Add 741 bundled UI translations and automatic Persian fallback translation for displayed content. Manual target-language content takes priority and editors remain untouched. Unavailable or quota-limited external translations preserve their originals with an explicit notice. The optional free MyMemory service is quota limited; no paid provider credentials are configured.

Validation: production build, authorization/referral/commission integration tests, legacy fee upgrade, note history, currency rounding and translation provider contract tests. Interactive browser QA is unavailable in this workspace.
