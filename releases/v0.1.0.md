# MissMahta v0.1.0 — نسخه پایه طراحی

تاریخ ثبت: ۲۰۲۶-۰۹-۰۸

این نسخه، نقطه شروع نسخه‌بندی طراحی و کد MissMahta است و برای بررسی و آزمایش ارائه می‌شود.

## امکانات موجود

- صفحه اصلی، ارتباط با مدیریت و طراحی فارسی راست‌به‌چپ با پشتیبانی از انگلیسی و حالت تیره.
- فهرست و پرتفولیوی معلمان با فیلتر زبان، کلاس آنلاین یا حضوری و هزینه.
- انتخاب واحد قیمت دلار یا تومان و ارسال درخواست کلاس به مدیریت.
- بلاگ معلمان و پنل مدیریت پروفایل و مقاله‌ها.
- فضای کار معلم شامل زبان‌آموزان، تقویم کلاس، ارزیابی مهارت و ثبت تسویه شهریه.
- تنظیمات ساخت و ذخیره‌سازی برای Netlify و ورود حساب‌های معلم و مدیر.
- نام MissMahta در لوگوها، صفحات، پنل، عنوان مرورگر و متن‌های ایمیل.

## اعتبارسنجی و وضعیت انتشار

- بیلد Netlify پس از تغییر نام با موفقیت تکمیل شده است.
- این Release نسخه کد و طراحی را نگه می‌دارد؛ انتشار روی هاست جداگانه انجام می‌شود.
- هنگام ثبت این نسخه، بازنشر Netlify به‌دلیل پایان اعتبار حساب مسدود است؛ سایت آنلاین هنوز تمام تغییرات این نسخه را نشان نمی‌دهد.
- داده‌های واقعی، تصاویر بارگذاری‌شده و رمزها جزو فایل دانلود این Release نیستند. این بسته جایگزین پشتیبان پایگاه داده نیست.
- ذخیره‌سازی Netlify فعلی برای آزمایش و سایت کوچک طراحی شده است؛ بررسی مرورگری کامل این نسخه انجام نشده است.
