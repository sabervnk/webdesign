# Classer v0.10.0

- Balance private account details in two responsive columns, with workspace preferences on the left in Persian. Require a valid email and mobile when explicitly saving account details, normalizing Iranian mobile numbers; retain compatibility for unrelated saves of legacy profiles. Email/SMS ownership verification remains deferred.
- Add server-verified, browser-bound raster CAPTCHA with a two-minute expiry and atomic single use for local sign-in and recovery requests. Keep independent account/IP limits, origin validation, secure sessions and a honeypot.
- Format Persian dates as weekday, Persian comma, day, month and year in Tehran time.
- Replace private message drafts and email/copy actions with authenticated, bidirectional teacher/student conversations stored in a separate database table. Include read receipts, incremental history, scoped authorization, idempotent sends and rate limits. Administrators can inspect threads but cannot impersonate participants.
- Retain historical drafts as explicitly unsent private notes. Direct messages require an active learner account linked to the correct teacher roster record. Settlement requests use the same direct messaging channel.
- Restyle the rich message editor, toolbar, message bubbles, conversation list and send action for desktop and mobile.

Validation: targeted date/contact/CAPTCHA and session-finance tests locally, followed by production build and Worker integration tests in CI. Browser visual QA is unavailable in this environment.
