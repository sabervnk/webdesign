# Classer v0.4.0

- Teacher dashboard memo board with an editor, preview, pinning, editing and deletion. Notes remain in the teacher's private workspace.
- Visible temporary-password fields, required email and mobile for newly provisioned users, and mandatory password change before access to a role's panel.
- Preserve existing 600,000-iteration password hashes while handling the Workers WebCrypto iteration cap.
- Users section combines accounts, roles and teacher portfolios. Local administrators cannot provision accounts or access private teacher workspaces; the verified owner retains superadministrator control.
- Administrative overview with real aggregate account, portfolio and inquiry counts.
- Live 24-hour Tehran clock and localized Persian calendar date.
- Multiple named class offers for each language and format, with independent duration, fee and currency. Class inquiries identify the selected offer and retain its server-validated quote.
- Public gender, education, certificates, specialties, biography and class offers are editable in the public portfolio form. Administrators can create portfolios before a teacher's first login.
- Additive database migrations preserve existing accounts and data.

Email recovery remains disabled until a verified sending identity and provider key are configured. No SMS delivery is configured.
