# Classer v0.7.0

- Make the username/password sign-in entry prominent for teachers, students and administrators. Keep ChatGPT sign-in optional for the verified site owner.
- Remove the teacher-directory shortcut from the teacher's portfolio workspace.
- Add subtle completed and cancelled class colors while keeping overdue review warnings distinct.
- Replace free-form time entry with two-digit hour/minute controls, automatic focus advance, Persian/Arabic digit normalization and time paste support.

- Preserve per-user/per-class drafts in the current browser tab, prevent accidental outside/Escape dismissal and restore drafts after explicitly closing and reopening the form.
