# Classer v0.6.0

- Bundle pinned Quill 2.0.3 as the shared editor for blog posts, teacher biographies, notes, feedback and message drafts. Preserve existing article text and media without storing executable HTML.
- Redesign the private Memo Board as a graphical notebook with paper cards, pins, color choices, search and a standard editor.
- Remove the duplicate dashboard learning summary.
- Move qualifications and specialties to the beginning of Profile and fix the gender control.
- Move site-wide content editing into its own Content Studio page, separate from administration controls.
- Keep prior status notes when a class changes status, and allow notes on paid classes while protecting their financial records.
- Highlight scheduled classes after their end time in Tehran and provide a review reminder.
- Calculate class fees from the original booking rate and duration, with currency-aware rounding and validation. Subsequent student price changes do not reprice historical bookings.
