# Classer v0.9.1

Fix the shared teacher settings/blog component receiving a `section` option without declaring it. After `/api/studio` loaded successfully, that undeclared name crashed both `/studio` and `/journal` in the browser. Declare a typed, defaulted mode prop so settings and the standalone blog render correctly.

Add a TypeScript semantic regression check for unbound runtime names in the shared studio/workspace components, plus authenticated teacher, administrator and anonymous route checks. Keep administrator and teacher permissions separate.
