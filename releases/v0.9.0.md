# Classer v0.9.0

- Separate administration and teaching roles at the page and API boundaries. Administrators land in `/admin` and cannot enter their own teacher workspace or studio. Preserve historical workspaces as labelled legacy records, rather than turning administrator sign-in into a teacher account.
- Give site administrators operational access to all user information, teacher records, requests, content and finances. Owner-only safeguards remain for creating or modifying other administrator credentials.
- Introduce an independent responsive admin shell with a navy sidebar, compact typography, overview cards, recent requests, follow-up tasks and financial summary. Redesign the request inbox with search, status/type filters, request reader, contact cards, note history, preserved follow-up drafts and an approval/commission preview.
- Move the introduction video to the end of the Profile tab. Rename the teacher settings page and add a separate Blog route in the sidebar.
- Add a reversible Archive state alongside Trash. Archived posts retain their content and translations, disappear from listings and direct public URLs, and can be restored. Keep ownership and publication checks on every transition.
- Refine the commission form layout and student exceptions. Reduce overall UI scale and spacing, retain mobile form legibility, and provide placeholders for numeric and phone inputs.

Validation includes production build, role isolation, administrator record access, archive visibility/restoration, fee integrity and existing security regressions. Interactive browser QA is unavailable in this environment.
