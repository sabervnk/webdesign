# Classer v0.5.0

- Merge qualifications into the public teacher About tab.
- Redesign teaching portfolio sections and named class offer cards, including a dedicated in-person location panel.
- Preserve empty money inputs and use a zero placeholder.
- Add a teacher publishing dashboard with search, status filters, drafts, trash and restoration.
- Add a formatting toolbar, safe preview, links, headings, lists, quotes, images and video to the post editor.
- Add featured images, excerpts, tags, author-owned categories and translated text.
- Add local draft autosave and an author-owned media library. Draft media remains private; published media becomes available only through a published article and portfolio.
- Preserve existing articles and portfolios through additive database migrations and legacy-compatible text rendering.
