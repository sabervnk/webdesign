# Classer v0.2.1 — پرونده‌های قابل ویرایش و ساخت حساب

- جایگزینی نمایش JSON با فرم‌های پرتفولیو، بلاگ، حساب معلم، زبان‌آموزان، جلسه‌ها، ارزیابی‌ها و پیام‌های پرونده.
- حداقل ۸ نویسه برای رمز جدید، نمایش قدرت رمز و جلوگیری از ثبت رمزهای خیلی ضعیف.
- استفاده از API سازگار میزبان برای هش رمز، با حفظ سازگاری با رمزهای ذخیره‌شده.
