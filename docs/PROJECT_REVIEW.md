# بررسی MissMahta — ۲۰۲۶-۰۹-۰۸

نسخه پایه: [v0.1.0](https://github.com/sabervnk/webdesign/releases/tag/v0.1.0)
نسخه اصلاحی این بررسی: v0.1.1

## دامنه و نتیجه

کد بخش‌های عمومی، ورود Netlify، پنل معلم، مدیریت درخواست‌ها، مدل داده، ذخیره‌سازی، تنظیمات ساخت، طراحی واکنش‌گرا و آزمون‌های موجود بررسی شد. ساختار فعلی امکانات اصلی یک نمونه آزمایشی را دارد؛ برای استفاده گسترده و داده‌های واقعی، کارهای اولویت‌دار زیر باقی است.

این بررسی شامل آزمون نفوذ کامل، ارزیابی حقوقی، آزمون بار واقعی و کنترل بصری در مرورگر و دستگاه‌های مختلف نیست. هیچ داده، حساب یا رمز واقعی برای آزمایش تغییر نکرد. آزمون‌ها از حساب‌های ساختگی و ذخیره‌سازی محلی موقت استفاده می‌کنند. گزارش، تضمین نبود هرگونه خطا نیست.

## ترتیب پیشنهادی کار بعدی

1. انتشار نسخه اصلاحی و آزمون واقعی ورود، پروفایل و درخواست کلاس؛ تنظیم پشتیبان اطلاعات.
2. حساب‌ها و ابزار مدیر: بازیابی رمز، دعوت و لغو دسترسی، مدیریت معلم‌ها.
3. کیفیت استفاده روزمره: زبان پرونده، منطقه زمانی، محافظ متن ذخیره‌نشده و اعلان درخواست.
4. پنل زبان‌آموز، تکلیف، گفتگو و رسیدهای شهریه بر اساس اولویت کاربر.
5. امکانات تکمیلی مانند رزرو خودکار، پرداخت آنلاین، ویدئو و نظرات تأییدشده.

ممیزی مبتنی بر npm audit است؛ وجود هشدار یک بسته به‌تنهایی اثبات بهره‌برداری‌پذیری آن در مسیرهای این سایت نیست. نتیجه اجرایی و ابزارهای توسعه جداگانه ثبت می‌شوند.

## نتایج اعتبارسنجی نهایی

- بیلد Sites/Vinext با Vite 8.2.2: موفق.
- بیلد Next.js 16.3.4 برای Netlify به‌همراه TypeScript: موفق.
- آزمون‌های مدل داده و HTTP: ۱۲ سناریو موفق؛ دقت پول، قفل سوابق، تاریخ تسویه، JSON نامعتبر و بدنه chunked بزرگ بررسی شدند.
- آزمون هم‌زمانی ذخیره‌سازی Netlify در نمونه‌های مستقل: موفق.
- دو آزمون یکپارچه Sites/D1/R2: موفق؛ مالکیت، پیش‌نویس، عکس، نرخ تاریخی و لینک‌های خارج از سقف فهرست پوشش داده شدند. تنظیمات آزمون با API جدید Miniflare از طریق تبدیل‌گر رسمی آن سازگار شد.
- آزمون یکپارچه Netlify با سرور production و شبیه‌ساز رسمی Blobs: موفق؛ از جمله تلاش هم‌زمان، سقف پنج درخواست، رسید تکراری پس از تغییر نرخ و حفظ داده پس از راه‌اندازی مجدد. مجموع ۱۶ سناریوی آزمون در اجراهای نهایی مرتبط پاس شدند.
- `npm audit --omit=dev`: صفر هشدار در وابستگی‌های دسته‌بندی‌شده اجرایی.
- `npm audit` کل پروژه: ۶ بسته دارای هشدار باقی است؛ ۲ مورد high (`image-size` و وابسته‌اش `vinext`) و ۴ مورد moderate (`esbuild` قدیمی و زنجیره `@esbuild-kit` / `drizzle-kit`). چند نام در این شمارش از یک وابستگی ریشه ناشی می‌شوند.

این شش مورد رفع نشده‌اند. image-size تا نسخه موجود 2.0.2 هشدار parser تصویر دارد و راهکار پیشنهادی npm برای Vinext ارتقا به 1.0.0-beta.9 است. برای Drizzle نیز پیشنهاد خودکار npm به نسخه قدیمی‌تر و ناسازگار می‌رود؛ `audit fix --force` اجرا نشد. رفع این موارد باید در تغییر کنترل‌شده بستر Sites/ابزار مهاجرت انجام شود. قرار گرفتن Vinext در devDependencies به‌معنای بی‌ارتباط بودن آن با خروجی Sites نیست؛ صفر هشدار وابستگی‌های اجرایی، ادعای امنیت کامل هر دو بستر نیست.

صفحات تولیدی Next و APIها در محیط محلی آزموده شدند؛ بسته‌بندی نهایی Netlify Runtime و رفتار روی هاست و مرورگر واقعی برای این نسخه هنوز تأیید نشده است. به‌علت مانع اعتبار Netlify، در این مرحله انتشار مجدد روی هاست درخواست نشد.
